# SharePoint IAC
**Infrastructure as code**(*IAC*) for SharePoint configurations.

## Purpose
SharePoint is notoriously hard to log and manage without jumping through hoops or paying an arm and a leg to have someone manage it for you. This Repo is meant to help manage as much as possible through Infrastructure As Code.

# About The Project
## Rant about SharePoint
### The Good
SharePoint is a fantastic tool to allow non-power-users to create some amazing stuff:
* create websites with no coding experience
* create file shares without network sharing knowledge
* manage file permissions without knowing ADUC
* collaborate in truly awesome ways.
### The Bad
SharePoint can easily become a black hole of time and energy. Letting your user base create whatever they want can lead to:
* an eldritch horror permission structure that will lead you to madness
* A site collection or subsite for every little project, thought, or astrology chart that your users can think of. 
### The Solution!
Build your infrastructure with intent, operate with least privilege, and jam your configuration into SharePoint with *IAC* as often as feasible.

That last part is what I am trying to figure out with this project!
